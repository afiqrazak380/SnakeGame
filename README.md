# Snake Game 🐍

A classic Snake game built from scratch using vanilla JavaScript and the
HTML5 Canvas API.

🔗 **Play it live:** [snakekey.netlify.app](https://snakekey.netlify.app)

## How to play

- Use the arrow keys to control the snake's direction
- Eat food to grow and increase your score
- Avoid hitting the walls or colliding with yourself
- Press the reset button to start a new game after game over

## Built with

- HTML5 Canvas
- Vanilla JavaScript (game loop, collision detection, state management)
- CSS

## Running locally

```bash
git clone https://github.com/afiqrazak380/SnakeGame.git
cd SnakeGame
open index.html
```
